# Q/A SET 1 — KEY POINTS + FLASHCARDS

---

## 🔑 KEY POINTS (AI-900 Quick Revision)

### Azure AI Services
- **Model Catalog** → Use pre-trained models without training from scratch
- **Grounding Data (RAG)** → Add latest knowledge without retraining
- **DALL·E** → Create + Modify images
- **Azure AI Vision** → OCR (printed + handwritten text extraction)
- **Document Intelligence** → Extract structured data (invoices, receipts)

---

### AI Workloads
- **Computer Vision**
  - Image classification, object detection, OCR
  - Example: crop classification, health scan analysis

- **NLP (Natural Language Processing)**
  - Text classification, sentiment analysis, translation
  - Works with **text + speech (via speech-to-text)**

- **Knowledge Mining**
  - Extract insights from unstructured data (contracts, docs)

- **Generative AI**
  - Creates new content (images, text)

---

### NLP Concepts
- **Sentiment Analysis** → Positive / Negative / Neutral classification
- **Text-to-Speech** → Converts text → audio
- **Speech-to-Text** → Converts audio → text

---

### Machine Learning Basics
- **Clustering** → Group similar data points
- **Classification** → Predict category
- **Regression** → Predict continuous values

---

### Transformers
- Uses:
  - **Self-attention**
  - **Encoder-Decoder architecture**

---

### Responsible AI Principles (VERY IMPORTANT ⚡)

- **Fairness** → No bias
- **Privacy & Security** → Protect personal data
- **Reliability & Safety** → Testing, avoid harm
- **Transparency** → Explain decisions
- **Accountability** → Governance + responsibility
- **Inclusiveness** → Benefit everyone
